# AI Architectural Prompts – TaskMatrix

This document records the AI-assisted architectural research and planning prompts used during the TaskMatrix Capstone project.

## 1. Product Requirements

**Prompt:**

Act as a senior product manager. Help me define a comprehensive Product Requirements Document for an enterprise Agile project management platform named TaskMatrix. Include user roles, business requirements, core modules, functional requirements, non-functional requirements, MVP scope, and development priorities.

## 2. System Architecture

**Prompt:**

Act as a senior full-stack software architect. Design a scalable modular monolith architecture for TaskMatrix using Next.js, TypeScript, FastAPI, SQLAlchemy, and PostgreSQL. Explain frontend-backend communication, API organization, authentication, authorization, and real-time updates.

## 3. Database Architecture

**Prompt:**

Design a normalized PostgreSQL database schema for TaskMatrix. Include Users, Workspaces, Workspace Members, Projects, and Tasks. Define primary keys, foreign keys, relationships, constraints, and indexes.

## 4. API Design

**Prompt:**

Design REST API endpoints for an Agile project management platform. Cover authentication, workspaces, workspace members, projects, tasks, task assignment, and activity tracking. Include HTTP methods, request payloads, response structures, and authorization requirements.

## 5. UI/UX Planning

**Prompt:**

Act as a senior UI/UX designer. Create a modern SaaS dashboard design plan for TaskMatrix. Include authentication, workspace dashboard, project overview, Kanban board, task details, and team management. Ensure desktop and mobile responsiveness.

## 6. Security Planning

**Prompt:**

Identify security requirements for a multi-user project management SaaS application. Explain JWT authentication, password hashing, role-based access control, workspace-level data isolation, input validation, and API protection.

## 7. Development Roadmap

**Prompt:**

Prepare a realistic four-week implementation roadmap for TaskMatrix after its planning phase. Prioritize MVP development, CRUD functionality, real-time updates, AI integration, testing, and deployment.

---

*AI assistance is used for architectural research, planning, and technical documentation. Final implementation decisions and code will be reviewed and validated by the developer.*
